# 心智随身听 · 技术架构

## 目标与范围

本地私人使用的长音频 PWA。保留黎雄2026-10-31聚会原声、12个章节、黄明哲正解道德经107集和原播放进度，新增用户已授权导入的万力豪《别人的态度，逼出你的什么？》单集。支持专题选集、顺次播放、单曲循环、倍速、A-B复读、逐集续播及主动离线缓存。锁屏、耳机与真机长期后台行为必须逐项实测，MediaSession注册本身不等于通过。用户已于2026-11-09 Asia/Shanghai授权主会话发布现有GitHub Pages应用壳；本候选尚待主会话完成最终完整门禁、实际发布与线上制品核验，不能称已上线。私有音频不公开。

## 技术栈

原生HTML/CSS/JavaScript，无打包及第三方前端依赖；HTMLAudioElement解码；IndexedDB存储音频Blob；LocalStorage存储偏好和进度；Service Worker/CacheStorage缓存应用壳并兼容旧媒体Range请求。Node标准库提供本地Range服务器和验收入口，Python标准库运行技术文档同步检查。不存在业务后端或云端同步。

## 模块与目录

- `index.html`、`styles.css`：沿用深色单栏播放器，专题选择在播放器上方，有序目录在其下；页面本身拥有滚动，不设嵌套列表滚动。
- `tracks.js`：原黎雄元数据、12章与金句；`course-data.js`：107集及Hope单集专题静态元数据与私人备份文件夹名。数据插入界面用textContent，不将标题作为HTML执行。
- `app.js`：选集、播放状态、逐集进度、缓存队列与Service Worker注册。
- `controls.js`：播放按钮、键盘可用的原生进度滑块、倍速、单曲循环、A-B、章节与MediaSession。
- `importer.js`：文件夹/多文件选择、预检、顺序导入、停止与继续；SHA256和bytes写入前校验。
- `storage.js`：沿用IndexedDB库与事务；音频下载、长度/MIME/解码元数据验证、写入完成确认。
- `sw.js`：版本化应用壳缓存，保留旧v2媒体缓存，支持mp3和m4a的Range。
- `scripts/serve.mjs`：仅loopback本地服务器，只开放应用壳与public/audio、public/icons，拒绝私有文档和.git；`scripts/acceptance.mjs`：唯一完整验收入口。
- `docs/acceptance.json`：必需验收清单；`docs/qa/`与`.omo/evidence/topic-player/`：来源、原始日志、截图和回执。
- `public/audio/lixiong-20261031.mp3`：保留原录音；`public/audio/daodejing/001.m4a`至`107.m4a`及`public/audio/hope/hope-workplace-03.mp3`：真实本地私人音频，两个课程目录均已加入.gitignore。

## 数据模型

专题为`{id,title,speaker,tracks,backupFolder}`，backupFolder仅私人课程使用；音轨为`{id,title,speaker,duration,audioSrc,mime,chapters,sourceUrl,bytes,sha256,fileName,privateAudio}`。原音轨不要求新增来源字段；107集课程MIME为`audio/mp4`，Hope原始MP3为`audio/mpeg`。时长与bytes取真实下载制品探测，官方原始目录单独保存，不能用本地产物反推来源覆盖。

IndexedDB保持`MindWalkmanDB`版本1、`audio_files`对象仓库、音轨ID主键，旧黎雄Blob无需复制。LocalStorage使用`mw_pos_<id>`保存秒数、`mw_lastTrack`保存当前音轨、`mw_speed`保存倍速、`mw_loop`保存`normal`或`one`。旧`mw_pos`仅迁移为黎雄进度并继续写回兼容。A-B点只存在当前会话，切集即清除。续播书签在完成时归零；新增 mw_progress_<id> 保存 completed、furthest、duration，独立保留完成状态。专题末尾停止且可重新播放。

## 接口与契约

音频相对路径必须对应本地媒体；HTTP服务器必须支持完整200及字节范围206。新缓存检查200响应、音频MIME、非空长度（有bytes时严格相等）和浏览器实际解码元数据；必须等IndexedDB transaction complete才能标记已缓存，事务中止、配额不足及错误响应不能显示成功。

MediaSession的play/pause、seekbackward/forward、seekto映射同一播放器；previoustrack/nexttrack切换当前专题的音轨，章节通过原章节按钮定位。浏览器不支持的系统action忽略NotSupportedError，其余异常保留。SW仅处理同源GET，媒体返回真实MIME，支持闭区间、开放尾区间和后缀Range，不满足范围返回416。

## 关键流程

选集先保存旧进度、暂停并清空旧源，递增选择序号，读取本地Blob后核对序号；过期结果不能覆盖新音轨。载入metadata并恢复进度后才允许保存，避免载入中的0秒覆盖书签；之后恢复倍速、按用户操作启动播放。ObjectURL离开音轨时释放。

新安装默认顺次播放，结束后进入本专题下一集，最后一集停止；用户可选择单曲循环。A-B仅在B>A时启用；切集恢复用户顺次/单曲偏好。

用户主动点击缓存本集或缓存整专题才下载音频。整专题顺序处理，已有缓存跳过；停止按钮停止后续任务，已进入事务提交的当前集允许完成。失败保留先前完成项并显示原因；缓存完成不切换正在播放的src，避免播放跳动和异步覆盖。应用壳由SW安装时预缓存；在线播放本身不承诺完整音频缓存。离线状态只根据本集实际缓存展示。

## 安全与隐私

个人进度与音频仅保存在浏览器本地，无第三方统计、账号、上传和追踪。浏览器可回收IndexedDB/CacheStorage，缓存不是永久硬件保证；清除站点数据会丢失缓存及进度。下载失败不影响已完成音轨。新课程媒体从Git排除，源标题/ID/URL不含认证令牌。测试服务器仅绑定127.0.0.1且路径解码后检查目录穿越、白名单及realpath，不对局域网公开内部文件。
