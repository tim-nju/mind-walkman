# 心智随身听 · 技术架构

## 目标与范围

长音频 PWA，支持专题、逐集进度、离线音频和通用私人目录导入。已上线版本仍以浏览器本地存储为主；本地候选新增个人收听自动同步服务，尚未部署。保留既有公开音轨、课程、专题与书签。私人录音标题、日期、文件指纹和媒体不进入个人收听同步接口；加密交付与本地文件导入的独立边界见下文。

## 技术栈

原生 HTML/CSS/JavaScript，无构建器及第三方前端依赖。HTMLAudioElement 解码播放；IndexedDB 存储音频 Blob，并以独立 MindWalkmanSync 数据库保存授权、同步状态和事务待上传队列；LocalStorage 保留目录及旧进度兼容投影；Service Worker 缓存应用壳。新增 Node HTTP 服务使用 pg 连接 PostgreSQL，锁文件固定依赖；Node 提供测试与验收，Python 标准库提供技术文档检查。

- storage.js：IndexedDB 事务、音频长度与 SHA256 校验、网络下载边界。
- sw.js：v15-sync 应用壳缓存，统一 v15 版本 URL 并加入同步模块；保留旧 v2 媒体缓存及 Range 兼容。

## 数据模型

IndexedDB 沿用 MindWalkmanDB v1 的 audio_files 仓库，以音轨 ID 存 Blob。LocalStorage 的 mw_pos_<id> 是续播位置，mw_progress_<id> 保存 completed、furthest、duration；mw_lastTrack 保存全局最后音轨，mw_lastTrack_<topicId> 记录各专题最近选集/收听集数，mw_speed、mw_loop 保存偏好。旧 mw_pos 兼容原音轨。

候选同步模型以毫秒保存 positionMs、furthestMs、durationMs、completed；旧格式仍以秒表示。音轨 key 为账号派生密钥的 HMAC，偏好只有 speed、loop、lastTrack。每条记录的 stamp 为 origin、逻辑 counter、服务端分配 actor 和同次操作 sample；不以设备墙钟决定续播。服务端历史版本、幂等操作及授权 hash 分开持久化，所有读写绑定内部单人 owner。

mw_private_catalog 保存私人目录数组。每项为 {id,title,date,fileName,duration,bytes,sha256,mime}；ID 必须为 private- 前缀的受限字符串且唯一。文件名必须唯一、可由系统选择器直接提供，拒绝路径、控制字符、冒号、点路径及首尾空白。大小必须为正安全整数、时长为正有限数、SHA 为64位小写十六进制；MIME 限 audio/mp4、audio/mpeg、audio/ogg。解析结果强制 privateAudio 和 localOnly，audioSrc 为空，字段不作为 HTML 执行。

## 接口与契约

同一私人 ID 的 bytes/SHA256 为不可变内容身份；发生冲突时在写入前拒绝。同身份保留原元数据，新 ID 追加，旧目录缺席条目继续保留。目录不是删除入口。不存在目录与合法空数组可加载；损坏 JSON、无效结构、存储读写失败必须显示错误且保留旧值。

音频导入在写入前校验 bytes 与 WebCrypto SHA256，等 IndexedDB transaction complete 后才显示成功；已缓存条目可跳过。localOnly 禁止所有网络下载路径，普通私人课程在非 loopback origin 同样不能下载媒体。公共页面只有程序，不拥有私人 iCloud 访问权。

## 关键流程

先由文件选择器导入私人目录，保存后重载页面，再选择私人专题和对应音频文件、预检数量并确认导入。目录使用 LocalStorage、媒体使用 IndexedDB，均绑定当前 origin 与浏览器；在电脑浏览器导入不会填充手机的数据库。

选集先保存旧进度、暂停并清空旧源，以选择序号拒绝过期异步读取；metadata 恢复书签后才允许保存，避免0秒覆盖。收听专题切换（#topicSelect）通过 findActiveTrack(topic) 依次按专题专属记忆（mw_lastTrack_<topicId>）、全局记忆、未完成断点及已完成推进顺位选定目标集数，并在渲染后经 scrollToActiveTrack 自动平滑滚动聚焦目标剧集行，触发 track-row-locate-pulse 脉冲高亮；并在播放器导航栏增设“定位目录”按钮、专题目录头部增设“📍 定位当前集”按钮。结束时书签归零但独立完成状态保留，顺次播放同专题下一集，末集停止。A-B 不跨曲保留。导入/下载逐集执行；停止阻止后续项，已进入事务的当前项允许完成。配额、权限、校验失败显示真实结果，不覆盖已有音频或目录。

## 安全与隐私

无统计或追踪。旧线上版无业务同步；候选版只在设备授权后上传白名单进度与偏好，不上传原始音轨 ID、私人标题、目录、媒体地址、文件指纹或音频。私人目录和录音仍由本地导入/独立加密交付管理。公开提交采用明确文件清单，不新增明文媒体、私人报告、绝对宿主路径或私人录音元数据。凭据不进日志、URL或仓库；浏览器凭据绑定精确服务 origin，Mac 凭据另存钥匙串。IndexedDB 不是 HttpOnly 防护，不宣称能抵御同源脚本失陷。

本地文件 SHA 回读只证明本机副本一致，不证明 iCloud 远端同步或手机可见。浏览器可回收存储；清除站点数据会丢失本地媒体和进度。上线不能远程写入用户手机 IndexedDB，设备第一次使用私人内容仍需要本人通过系统文件选择器导入。

## 技术决策

公开程序、私人媒体交付和个人收听数据分别处理：音频仍使用 Blob 离线播放；收听记录新增独立后端，复用备份协议而不改日课服务或混用其用户数据。内容身份约束置于目录持久化边界，媒体校验置于文件写入边界。旧发布例外与本轮代码/设备验收分开记录，不继承历史例外授权。

## 加密私人收听交付（本轮设计）

目标是无需选择本地目录即可在用户打开私人收听链接后下载、解密、校验并缓存录音。沿用无后端、无第三方依赖架构；新增private-delivery.js负责收听入口，sealed-media.js负责AES-GCM解密协议，scripts/seal-media.mjs负责本机封装。公开public/sealed目录只含随机标识与密文，标题、日期和SHA放入加密manifest；32字节随机密钥只保存在.private-media及私人链接fragment，不提交、不放HTTP查询参数或日志。不把密钥写入公开页面。持有完整链接的人可解锁，链接须按私人文件保管。

每个分块独立AES-256-GCM加密，12字节随机IV、128位tag，AAD绑定随机包ID及分块编号；manifest也加密并绑定ID。2026-11-10实测大请求上传超时而小密文可写，封装改为1MiB分块；加密manifest携带partSize，客户端只允许512KiB、1MiB、8MiB三种大小，最多1024块及512MiB总量，旧包默认8MiB。浏览器顺序解密，再经既有bytes/SHA校验导入IndexedDB；失败不覆盖已有音频/目录。目录合并保持ID内容身份不变，成功后设置最后收听音轨并移除URL中的密钥。断网已缓存可继续播放；失败保留本页重试入口，刷新可重新打开私人链接。原始录音不变，密文可公开传输，密钥丢失无法恢复，只能重新从私人原件封装。重新封装必须生成全新随机IV，不能复用旧IV。

此通道明确扩展此前localOnly的交付边界：既有明文网络下载仍禁止，仅新独立入口允许下载密文；本地解密后音轨仍为localOnly。公开服务可以观察密文大小和访问时间；不能宣称隐藏全部元数据。本站脚本和设备本身是可信边界，没有外部统计/脚本。浏览器站点数据与独立PWA可能隔离，不能声称点击Safari链接必然填充既有主屏幕App。首次打开链接需联网准备，后续同一存储上下文打开可直接点播放；自动有声播放受浏览器手势限制。

缓存升级统一v13，独立listen.html入口与index内容一致但避开旧首页缓存。安装从网络重载全部壳资源，新缓存名隔离已污染v12；仅清理旧shell缓存，保留音频与进度。新增验收保护篡改/错钥/错包、断网重试、旧数据保留、真实大文件解密播放以及污染旧壳升级；完整旧门禁不删减，缺失证据仍阻断完整通过。上线授权例外和实测范围分别记录。

## 个人收听自动同步（2026-11-09 实施设计，尚未部署）

用户本轮选择沿用“浏览器自动同步到服务器 → Mac 每小时自动备份到 iCloud”的路径，不接受日常手工导出。新增独立心智随身听后端与持久 PostgreSQL；保留 GitHub Pages origin，避免丢失已有浏览器记录。不修改日课服务或其数据。此前“无业务后端”描述仍是已上线现状；本节为待验证实现，不能冒充生产启用。

共享 sync-model.js 定义逐集记录和偏好寄存器；sync-client.js 在独立 IndexedDB 中以事务保存状态与待上传队列，旧 mw_* 保留并作兼容投影。完成状态取 OR、最远位置取 max；续播采用逻辑操作计数、设备 ID、同操作采样序号排序，重听允许回退。启动载入、远端合并及暂停中的定时回调不产生新操作。离线保留队列，联网、回前台和运行期间自动补传，未确认记录不删除；sourceId 改变时停同步并显示恢复要求。

新 server/ 仅接收严格白名单的进度和偏好，音轨 ID 先以账号专用 HMAC 派生，不上传私人标题、目录、文件名、媒体、媒体摘要或密文密钥。浏览器凭据和 Mac 导出凭据分离，服务端只存 hash。设备用一次性激活授权，之后自动同步；激活、撤销与生产恢复由私有管理命令执行。HTTPS、精确来源 CORS、请求限额、事务幂等与授权隔离为服务边界。

复用已安装 Personal Backup Kit 的 protocol 1 与现有 com.personal.backup 小时任务，仅在批准生产接入后新增 mind-walkman 配置；不重装调度、不改日课配置。快照包含固定 watermark 下的不可变记录版本及恢复派生密钥，不包含登录凭据。保留策略沿用组件最近30份与最近12个月月末份；恢复进入隔离空数据库先验证，生产恢复不自动执行。组件本地回读与 iCloud 云端上传分别留证。

实施契约与验收场景见 [个人收听同步实施契约](个人收听同步实施契约.md)。新增测试纳入既有完整验收清单；既有缺失/过期回执不删除、不伪造。生产 origin、PostgreSQL 账号与实际启用状态目前待核实，发布和一次性身份操作另行确认。

## 加密私人收听交付（本轮设计）

目标是无需选择本地目录即可在用户打开私人收听链接后下载、解密、校验并缓存录音。沿用无后端、无第三方依赖架构；新增private-delivery.js负责收听入口，sealed-media.js负责AES-GCM解密协议，scripts/seal-media.mjs负责本机封装。公开public/sealed目录只含随机标识与密文，标题、日期和SHA放入加密manifest；32字节随机密钥只保存在.private-media及私人链接fragment，不提交、不放HTTP查询参数或日志。不把密钥写入公开页面。持有完整链接的人可解锁，链接须按私人文件保管。

每个分块独立AES-256-GCM加密，12字节随机IV、128位tag，AAD绑定随机包ID及分块编号；manifest也加密并绑定ID。2026-11-10实测大请求上传超时而小密文可写，封装改为1MiB分块；加密manifest携带partSize，客户端只允许512KiB、1MiB、8MiB三种大小，最多1024块及512MiB总量，旧包默认8MiB。浏览器顺序解密，再经既有bytes/SHA校验导入IndexedDB；失败不覆盖已有音频/目录。目录合并保持ID内容身份不变，成功后设置最后收听音轨并移除URL中的密钥。断网已缓存可继续播放；失败保留本页重试入口，刷新可重新打开私人链接。原始录音不变，密文可公开传输，密钥丢失无法恢复，只能重新从私人原件封装。重新封装必须生成全新随机IV，不能复用旧IV。

此通道明确扩展此前localOnly的交付边界：既有明文网络下载仍禁止，仅新独立入口允许下载密文；本地解密后音轨仍为localOnly。公开服务可以观察密文大小和访问时间；不能宣称隐藏全部元数据。本站脚本和设备本身是可信边界，没有外部统计/脚本。浏览器站点数据与独立PWA可能隔离，不能声称点击Safari链接必然填充既有主屏幕App。首次打开链接需联网准备，后续同一存储上下文打开可直接点播放；自动有声播放受浏览器手势限制。
