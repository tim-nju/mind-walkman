# 心智随身听 · 技术架构

## 目标与范围

无业务后端的长音频 PWA，支持专题、逐集进度、离线音频和通用私人目录导入。保留既有公开音轨、课程、专题与书签。私人录音标题、日期、文件指纹和媒体只经本地文件选择器进入用户当前浏览器，不写入公开程序。

## 技术栈

原生 HTML/CSS/JavaScript，无构建器及第三方前端依赖。HTMLAudioElement 解码播放；IndexedDB 存储音频 Blob；LocalStorage 保存目录和进度；Service Worker 缓存应用壳。Node 标准库提供本地测试与验收，Python 标准库提供技术文档检查。

## 模块与目录

- index.html、styles.css：深色单栏界面、专题与有序目录，由页面承担滚动。
- tracks.js、course-data.js：既有静态专题与章节；私人录音不加入这些文件。
- app.js、controls.js：选择、播放、逐集书签、完成状态、倍速、A-B、MediaSession 与缓存队列。
- importer.js：私人 JSON 目录验证及合并，文件夹/多文件预检和顺序导入。
- storage.js：IndexedDB 事务、音频长度与 SHA256 校验、网络下载边界。
- sw.js：v12 精确版本 URL 的应用壳缓存；保留旧 v2 媒体缓存及 Range 兼容。
- scripts/acceptance.mjs、docs/acceptance.json：唯一完整验收入口及21项清单；测试与外部证据都必须满足。
- .private-media、.omo/evidence、docs/qa：本地私人制品与回执，不公开；既有公开来源映射例外保留。
- scripts/private-recording-browser-check.mjs：本地私人 QA 驱动，包含宿主及媒体上下文，仅在授权工作区保留；仍属于完整清单指纹输入，不从验收范围删除。

## 数据模型

IndexedDB 沿用 MindWalkmanDB v1 的 audio_files 仓库，以音轨 ID 存 Blob。LocalStorage 的 mw_pos_<id> 是续播位置，mw_progress_<id> 保存 completed、furthest、duration；mw_lastTrack、mw_speed、mw_loop 保存偏好。旧 mw_pos 兼容原音轨。

mw_private_catalog 保存私人目录数组。每项为 {id,title,date,fileName,duration,bytes,sha256,mime}；ID 必须为 private- 前缀的受限字符串且唯一。文件名必须唯一、可由系统选择器直接提供，拒绝路径、控制字符、冒号、点路径及首尾空白。大小必须为正安全整数、时长为正有限数、SHA 为64位小写十六进制；MIME 限 audio/mp4、audio/mpeg、audio/ogg。解析结果强制 privateAudio 和 localOnly，audioSrc 为空，字段不作为 HTML 执行。

## 接口与契约

同一私人 ID 的 bytes/SHA256 为不可变内容身份；发生冲突时在写入前拒绝。同身份保留原元数据，新 ID 追加，旧目录缺席条目继续保留。目录不是删除入口。不存在目录与合法空数组可加载；损坏 JSON、无效结构、存储读写失败必须显示错误且保留旧值。

音频导入在写入前校验 bytes 与 WebCrypto SHA256，等 IndexedDB transaction complete 后才显示成功；已缓存条目可跳过。localOnly 禁止所有网络下载路径，普通私人课程在非 loopback origin 同样不能下载媒体。公共页面只有程序，不拥有私人 iCloud 访问权。

## 关键流程

先由文件选择器导入私人目录，保存后重载页面，再选择私人专题和对应音频文件、预检数量并确认导入。目录使用 LocalStorage、媒体使用 IndexedDB，均绑定当前 origin 与浏览器；在电脑浏览器导入不会填充手机的数据库。

选集先保存旧进度、暂停并清空旧源，以选择序号拒绝过期异步读取；metadata 恢复书签后才允许保存，避免0秒覆盖。结束时书签归零但独立完成状态保留，顺次播放同专题下一集，末集停止。A-B 不跨曲保留。导入/下载逐集执行；停止阻止后续项，已进入事务的当前项允许完成。配额、权限、校验失败显示真实结果，不覆盖已有音频或目录。

## 安全与隐私

无统计、追踪、账号或业务上传。私人目录和录音仅在私人 iCloud 备份位置、授权工作区及主动导入的浏览器保存。公开提交采用明确文件清单，不新增媒体、私人报告、绝对宿主路径或私人录音元数据。先前公开音轨与静态课程保持，不扩大公开媒体范围。完整历史记录保存在本地忽略证据；公开架构只描述通用契约。

本地文件 SHA 回读只证明本机副本一致，不证明 iCloud 远端同步或手机可见。浏览器可回收存储；清除站点数据会丢失本地媒体和进度。上线不能远程写入用户手机 IndexedDB，设备第一次使用私人内容仍需要本人通过系统文件选择器导入。

## 测试与验收

唯一完整命令为 node scripts/acceptance.mjs；--check <id> 只输出 partial-pass，不能替代全量。21项清单及全部场景保持，不删减断言，不改写历史回执。私人最终回执要求 private-recording-final/v1 和8个有类型的场景报告，逐项校验源码、媒体、修复证据、真实命令退出码、运行环境、日志/截图 SHA及数值结果。缺失、失败、过期、篡改必须阻断完整验收。

本轮用户在获知上述限制后明确授权先上线，作为一次性发布例外单独留存本地。该决定不改变完整验收状态、未来发布要求或目标设备验证范围；不得称全量验收通过。最终 iOS 场景、真机锁屏/耳机及 iCloud 远端同步仍未验证。代码审查另记录同一目录文件失败后原地重选的低风险覆盖不足，本次不新增生产修改。

文档入口为 python3 scripts/check_technical_docs.py check --root .，审阅设计后显式 sync。公开检出不含私人媒体、宿主 QA 驱动和目标环境证据，不能据此宣称全量可验或通过。既有本机目录保留完整输入。发布另以实际线上 HTTPS 页验证，隔离浏览器结果不冒充 iOS。

## 技术决策

维持公开程序加本地私人导入，不为长音频新增后端或公开托管。Blob 完整播放减少离线 Range 依赖，SW 保留旧媒体升级兼容。内容身份约束置于目录持久化边界，媒体校验置于文件写入边界。发布冻结已经审查的生产代码；完整验收例外与代码审查分开记录。
