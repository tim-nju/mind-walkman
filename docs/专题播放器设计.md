# 专题播放器变更说明

主操作：播放/暂停。信息顺序：专题与当前集、播放控制、可选择的有序课程目录。
保留：黎雄标题、讲者、12个章节及金句、原进度、倍速、前后跳转、A-B、离线缓存。
新增：专题选择、上下一集、逐集进度与缓存状态、缓存整专题和停止下载。
样式来源：既有 styles.css 深色中性表面与暖色强调；本轮不重新设计装饰。
Layout: 播放页 - 专题选择与长目录 -> stack / content-limiter（既有项目布局）；scroll owner: document.scrollingElement；避免嵌套滚动与长标题溢出。
状态：加载、播放错误、未缓存、部分缓存、整专题缓存中、缓存失败、断网均显示事实，不能把断网写成离线可用。

## 私人文件导入
新用户选中道德经专题时，先看到“从 iCloud 导入课程”说明；提供文件夹和多文件两个入口。选择后显示选中/缺失数量，重名阻断，其他文件明确忽略，确认导入再写入。处理按集顺序，成功与部分成功不混称；停止后续导入保留已完成。网络公开环境隐藏本集/整专题HTTP缓存按钮，避免不可达操作。导入内容不会上传。
Layout: 导入区域 - 一次性文件准备与状态 -> stack / wrapping cluster，复用项目控件；scroll owner: document.scrollingElement；不使用模态层或双滚动。
