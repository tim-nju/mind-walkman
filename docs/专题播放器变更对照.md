# 心智随身听 · 本轮变更对照

## 当前结果

本轮准备在现有 [心智随身听](https://tim-nju.github.io/mind-walkman/) 应用壳中加入黄明哲正解道德经107集。课程音频保存在私人的 iCloud“应用备份 → 心智随身听 → 正解道德经”文件夹，由用户在播放器内选择并导入，不上传GitHub Pages。

**公开现网尚未更新，本轮没有提交、推送或部署。** 当前v9已完成桌面真实文件导入、离线重开及升级回归；iOS27.0模拟器也已实际导入107集，断开本地服务后强退重开，验证续播、首/中/末集跳转、自然连播及末集停止。模拟器使用本地Files提供器，不代表真机或iCloud跨设备同步。整体结论见下面唯一完整门禁的实际结果。

## 修改前 → 当前候选版本

| 区域 | 修改前 | 当前候选版本 | 对使用的影响 |
|---|---|---|---|
| 内容 | 黎雄单段录音 | 原录音与12章保留，另有107集道德经专题 | 可按顺序选集 |
| 私人音频准备 | 未提供课程 | 公开壳只含目录和校验信息，音频从iCloud文件夹导入 | 不公开上传课程，也不访问不存在的线上媒体路径 |
| 导入 | 无文件入口 | “从文件夹导入”或“选择音频文件”，选择后先显示集数和问题，再确认导入 | 可以完整导入，也可明确分批 |
| 文件检查 | 无对应检查 | 重名阻断，未知文件显示并忽略，缺失集数明确；逐文件SHA256和大小校验 | 错文件、未下载完整和内容损坏不能显示成功 |
| 内存与恢复 | 单录音下载 | 每次只处理一个文件；停止/失败保留已完成，重新选择跳过已有集数 | 不同时将整课1.47GB读入内存 |
| 播放进度 | 单个进度键 | 每集独立续播，兼容原黎雄旧进度 | 音轨间不覆盖书签 |
| 顺次播放 | 结束后停止 | 同专题下一集连续播放，最后一集停止且可重播 | 保持课程顺序 |
| 播放与缓存竞态 | 异步读取可能替换当前源 | 选集序号隔离旧结果，导入不打断正在播放的来源；当前缺失集导入后可点击播放 | 避免播放错集或覆盖进度 |
| 原版升级 | 缓存删除风险 | 保留旧v2媒体，升级后断网仍能播放旧录音 | 不要求重下载原录音 |
| iCloud备份 | 无课程备份 | 可重跑的复制脚本逐文件回读校验，已有不匹配文件拒绝覆盖 | 本地备份已验证不等于云端同步或手机可见已验证 |
| 验收 | 文档同步检查 | 媒体、备份、真实文件导入、播放、断网、升级、模拟器及独立审阅统一门禁 | 必需项缺失或证据过期会阻断完整交付 |

## 实际旧站点升级修复

iOS导入入口未显示的直接原因最终确认为旧测试服务器白名单拒绝`importer.js`（403）；重启后逐一验证全部依赖200。最初“混壳”判断是推断，未当作最终根因。另以真实旧SW控制新HTML的独立回归验证旧缓存风险：候选v9统一CSS/JS及SW注册版本URL，应用壳预缓存完全匹配；保留旧音频缓存，不强制刷新正在播放的页面。回归按正常页面注册更新，不用专门调用update替代用户路径。
